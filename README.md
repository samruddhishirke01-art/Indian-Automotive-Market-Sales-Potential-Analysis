# Indian Automotive Market Sales Potential Analysis

## 📌 Project Overview

This project analyzes the Indian automotive market to evaluate the potential for a Japanese car manufacturer to enter the Indian market and achieve an annual sales target of 10,000 cars.

The project uses data analysis and machine learning techniques to understand customer demographics, market segments, and potential customers. It also compares relevant Indian and Japanese market data to generate useful business insights.

## 🎯 Objectives

- Analyze the Indian automotive market.
- Compare relevant market data between India and Japan.
- Identify potential customers in India.
- Analyze customers based on age and gender.
- Identify the most promising customer segments.
- Estimate potential sales and revenue.
- Support data-driven decision-making for market entry.

## 📊 Key Analysis

The project includes:

- Basic dataset exploration
- Dataset structure and summary
- Memory usage analysis
- Customer demographic analysis
- Age-segment analysis
- Gender-based analysis
- Potential customer identification
- Top 10 potential customer analysis
- Sales potential estimation
- Revenue estimation
- Break-even analysis

## 🤖 Machine Learning

A machine learning model is used to identify potential customers based on available customer attributes.

The project includes:

- Data preprocessing
- Feature selection
- Model training
- Prediction of potential customers
- Exporting model features
- Generation of potential customer datasets
